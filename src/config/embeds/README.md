# Embeds predeterminados

1. En Discord, activá **Modo desarrollador**.
2. Clic derecho en el mensaje del embed → **Copiar ID**.
3. En el canal del mensaje (o indicando el canal):

```
/exportar-embed mensaje_id:ID formato:js
```

4. Copiá el código o descargá el archivo `.js`.
5. Guardalo acá, por ejemplo `carmeet.js`.
6. Importalo donde haga falta (comando `/panel`, etc.).

Los menús y botones de Sapphire **no se copian igual**: el comando te muestra un resumen de opciones para recrearlos.
